🎯 ПРЕЖДЕ ВСЕГО: ЧТО ТАКОЕ "ОБЛАКО"?

Облако = компьютер в интернете, который работает 24/7.

Представьте так:
- Ваш ПК дома - выключается ночью
- Облачный сервер - НИКОГДА не выключается

Когда вы выключаете свой ПК - бот перестаёт работать.
Когда бот на облаке - он ВСЕГДА работает!

═══════════════════════════════════════════════════════════════

❓ КАКИЕ ВОПРОСЫ У ВАС МОГУТ БЫТЬ?

1. "Как бот попадает на облако?"
   → Вы загружаете его на сервер

2. "Где я беру облако?"
   → На сайте Render.com (бесплатно)

3. "Как я туда загружаю бот?"
   → Через GitHub (как облачное хранилище)

4. "GitHub - это что?"
   → Облачное место для хранения кода

5. "Это сложно?"
   → НЕТ! Это очень просто (3 сервиса, 3 кнопки)

ЭТАП 1️⃣: GITHUB (ОБЛАЧНОЕ ХРАНИЛИЩЕ КОДА)

ЧТО ЭТО?
GitHub - это как Google Drive, но для кода.
Вы можете хранить там свой проект и делиться им.

КАК НАЧАТЬ?

Шаг 1: Откройте https://github.com/signup

Шаг 2: Заполните форму:
┌────────────────────────────────────┐
│ Email: ваша_почта@gmail.com        │
│ Password: сложный_пароль           │
│ Username: ваше_имя (запомните!)   │
└────────────────────────────────────┘

Шаг 3: Нажмите "Sign up"

Шаг 4: Подтвердите email (откройте письмо и нажмите ссылку)

✅ GitHub аккаунт готов!

ЧТО ДАЛЬШЕ?

Шаг 5: Создать репозиторий (папка для вашего бота)

Нажмите "+" (верхний правый угол) → "New repository"

┌────────────────────────────────────┐
│ Repository name: kontanta-bot      │
│ Description: KONTANTA Telegram Bot │
│ Public (выберите это!)             │
│ Create repository                  │
└────────────────────────────────────┘

✅ Репозиторий создан!

ТЕПЕРЬ: Загрузить туда свой код

На вашем ПК откройте PowerShell или CMD в папке бота:

C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot

Введите эти команды (одну за другой):

───────────────────────────────────────────────────────────

git init

(Это инициализирует Git)

───────────────────────────────────────────────────────────

git add .

(Это добавляет все файлы)

───────────────────────────────────────────────────────────

git commit -m "Deploy kontanta bot"

(Это создаёт "снимок" вашего кода)

───────────────────────────────────────────────────────────

git branch -M main

(Это выбирает ветку)

───────────────────────────────────────────────────────────

git remote add origin https://github.com/YOUR_USERNAME/kontanta-bot.git

(Замените YOUR_USERNAME на ваше имя GitHub!)

Например, если ваше имя "ivan123", то:
git remote add origin https://github.com/ivan123/kontanta-bot.git

───────────────────────────────────────────────────────────

git push -u origin main

(Это загружает код на GitHub)

При этом попросит GitHub пароль - введите пароль который создавали.

───────────────────────────────────────────────────────────

✅ Ваш код на GitHub!

═══════════════════════════════════════════════════════════════

ЭТАП 2️⃣: RENDER (ОБЛАЧНЫЙ СЕРВЕР)

ЧТО ЭТО?
Render - это сервис, который берёт ваш код из GitHub
и запускает его на облачном сервере.

КАК НАЧАТЬ?

Шаг 1: Откройте https://render.com

Шаг 2: Нажмите "Sign up"

Шаг 3: Выберите "Continue with GitHub"

Шаг 4: Авторизуйтесь через GitHub

✅ Render аккаунт готов!

ТЕПЕРЬ: Создать сервис для бота

Шаг 5: На главной Render нажмите "+ New"

Шаг 6: Выберите "Web Service"

Шаг 7: Выберите ваш репозиторий "kontanta-bot"

Шаг 8: Нажмите "Connect"

ЗАПОЛНИТЕ ФОРМУ:

┌────────────────────────────────────┐
│ Name: kontanta-bot                 │
│                                    │
│ Environment: Python 3              │
│                                    │
│ Build Command:                     │
│ pip install -r requirements.txt    │
│                                    │
│ Start Command:                     │
│ python bot.py                      │
└────────────────────────────────────┘

Шаг 9: Нажмите "Create Web Service"

ЖДЁМ ЗАГРУЗКИ (2-3 минуты)

Render будет:
1. Брать ваш код с GitHub
2. Устанавливать зависимости (pip install)
3. Запускать ваш бот

В консоли вы будете видеть логи.

═══════════════════════════════════════════════════════════════

ЭТАП 3️⃣: ДОБАВИТЬ ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ

ЧТО ЭТО?
Переменные - это важные данные (как BOT_TOKEN).
Они должны быть СЕКРЕТНЫЕ (не в коде).

Поэтому мы добавляем их отдельно в Render.

КАК ДОБАВИТЬ?

Шаг 1: На странице вашего сервиса в Render

Шаг 2: В левом меню найдите "Environment"

Шаг 3: Нажмите "+ Add Environment Variable"

ДОБАВЬТЕ 3 ПЕРЕМЕННЫЕ:

───────────────────────────────────────────────────────────

1️⃣ BOT_TOKEN

Key: BOT_TOKEN
Value: 123456789:ABCDefGHIjklmNoPqrsTuvWxyz1234567890

(Вставьте ваш токен от @BotFather)

───────────────────────────────────────────────────────────

2️⃣ ADMIN_ID

Key: ADMIN_ID
Value: 5785752307

───────────────────────────────────────────────────────────

3️⃣ WEBSITE_URL

Key: WEBSITE_URL
Value: https://www.kontanta.ru

───────────────────────────────────────────────────────────

Шаг 4: Нажмите "Save"

Render АВТОМАТИЧЕСКИ ПЕРЕСОБЕРЁТ БОТ!

❓ ЧАСТЫЕ ВОПРОСЫ:

Q: Мне нужна карточка?
A: НЕТ! Render полностью бесплатен.

Q: Бот всегда будет работать?
A: ДА! 24 часа в сутки, 7 дней в неделю, 365 дней в году.

Q: А если я выключу свой ПК?
A: БОТ БУДЕТ РАБОТАТЬ! Потому что он на облаке.

Q: Можно ли обновить код?
A: ДА! Измените файл на ПК → git push → Render обновится.

Q: Сколько это стоит?
A: БЕСПЛАТНО! Первые 750 часов в месяц бесплатны.

Q: Где я могу видеть логи бота?
A: Render → ваш сервис → "Logs" (внизу)
