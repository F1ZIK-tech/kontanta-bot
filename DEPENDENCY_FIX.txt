✅ РЕШЕНИЕ (3 шага)

1. Откройте PowerShell/CMD в папке проекта

2. Полностью удалите старое окружение:
   
   Windows: rmdir /s venv
   Linux/Mac: rm -rf venv

3. Создайте новое и установите:
   
   python -m venv venv
   
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate
   
   pip install -r requirements.txt

Всё! ✅

═══════════════════════════════════════════════════════════════

Если ошибка снова появится:

pip install --upgrade pip
pip cache purge
pip install -r requirements.txt
