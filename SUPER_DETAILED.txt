ШАГ 3: ЗАГРУЗИТЬ ВАШ КОД НА GITHUB (3 МИНУТЫ)

ОТКРОЙТЕ PowerShell (ДА, именно PowerShell!)

Как открыть PowerShell?

СПОСОБ 1 (ПРОСТОЙ):
1. Откройте папку: C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot
2. Нажмите Shift + правая кнопка мыши в пустом месте
3. Выберите "Открыть PowerShell здесь"

СПОСОБ 2:
1. Нажмите Windows + X
2. Выберите "Windows PowerShell"
3. Напишите: cd C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot

КОГДА PowerShell открыт, вы увидите:

C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot>

ТЕПЕРЬ КОПИРУЙТЕ И ВСТАВЛЯЙТЕ ЭТИ КОМАНДЫ (одну за другой):

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КОМАНДА 1:

git init

(Просто напишите и нажмите Enter)

Результат: нужно увидеть "Initialized empty Git repository"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КОМАНДА 2:

git add .

(Точка в конце важна!)

Результат: ничего, просто жду следующей команды

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КОМАНДА 3:

git commit -m "Deploy kontanta bot"

(С кавычками копируйте всё)

Результат: увидите что-то вроде "create mode 100644 bot.py"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КОМАНДА 4:

git branch -M main

(Просто скопируйте)

Результат: ничего

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КОМАНДА 5:

git remote add origin https://github.com/YOUR_USERNAME/kontanta-bot.git

ВАЖНО!!! Замените YOUR_USERNAME на ваше имя GitHub!

Пример:
Если ваше имя "ivan123", то:
git remote add origin https://github.com/ivan123/kontanta-bot.git

Результат: ничего

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КОМАНДА 6:

git push -u origin main

(Копируйте как есть)

Результат: Попросит GitHub имя и пароль

Напишите:
- GitHub username (имя): ivan123
- Password (пароль): ваш_пароль

После этого увидите разные сообщения о загрузке.

Когда всё закончится, увидите:

"branch 'main' set up to track 'origin/main'"

❓ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

1. Проверьте логи на Render
   (в правом нижнем углу сервиса)

2. Самые частые ошибки:

ОШИБКА: "Cannot find module"
РЕШЕНИЕ: Проверьте requirements.txt 
         (должны быть все зависимости)

ОШИБКА: "BOT_TOKEN is invalid"
РЕШЕНИЕ: Проверьте что скопировали токен полностью
         (с @BotFather без лишних пробелов)

ОШИБКА: "git not found"
РЕШЕНИЕ: Скачайте Git: https://git-scm.com/download/win
