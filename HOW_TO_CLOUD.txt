📋 ПОЛНЫЙ ПРОЦЕСС (2 аккаунта + код):

ЭТАП 1: GitHub (5 минут)
─────────────────────────

1. Перейдите на https://github.com/signup
2. Создайте аккаунт:
   - Email
   - Пароль
   - Юзернейм (запомните!)
   - Подтвердите email

3. Создайте репозиторий:
   - Нажмите "+" (верхний правый угол)
   - Выберите "New repository"
   - Назовите: kontanta-bot
   - Выберите "Public"
   - Нажмите "Create repository"

ЭТАП 2: Загрузить код на GitHub (5 минут)
──────────────────────────────────────────

1. Откройте CMD/PowerShell на вашем ПК
2. Перейдите в папку бота:
   cd C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot

3. Выполните команды:

   git init
   git add .
   git commit -m "Deploy kontanta bot"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/kontanta-bot.git
   git push -u origin main

   (ЗАМЕНИТЕ YOUR_USERNAME на ваше имя GitHub)

   При запросе введите GitHub логин и пароль

ЭТАП 3: Render.com (5 минут)
────────────────────────────

1. Перейдите на https://render.com
2. Нажмите "Sign up"
3. Выберите "Continue with GitHub"
4. Авторизуйтесь

5. На главной странице Render:
   - Нажмите "+ New" (верхний левый угол)
   - Выберите "Web Service"

6. Выберите репозиторий:
   - Найдите "kontanta-bot"
   - Нажмите "Connect"

7. Заполните настройки:
   ┌─────────────────────────────────────┐
   │ Name: kontanta-bot                  │
   │ Environment: Python 3               │
   │ Build Command:                      │
   │  pip install -r requirements.txt    │
   │ Start Command:                      │
   │  python bot.py                      │
   └─────────────────────────────────────┘

8. Нажмите "Create Web Service"

ЭТАП 4: Переменные окружения (2 минуты)
───────────────────────────────────────

Вот сервис создаёт, ждите загрузки (2-3 минуты).

Когда будет готово, в левом меню найдите "Environment":

Добавьте переменные:

┌──────────────────────────────────────────────────────────┐
│ BOT_TOKEN: 123456789:ABCDefGHIjklmNoPqrsTuvWxyz...     │
│ ADMIN_ID: 5785752307                                    │
│ WEBSITE_URL: https://www.kontanta.ru                    │
└──────────────────────────────────────────────────────────┘

Сохраните. Render автоматически пересоберёт бота!

❓ ЧАСТЫЕ ВОПРОСЫ:

Q: Бот не работает?
A: Проверьте:
   1. BOT_TOKEN правильный?
   2. Смотрите "Logs" на Render
   3. Перезагрузите сервис

Q: Как посмотреть логи?
A: На Render → ваш сервис → "Logs" (внизу справа)

Q: Как перезагрузить бота?
A: На Render → "Suspend" → "Resume"

Q: Как изменить код?
A: Измените файлы → git push → Render обновится

Q: Это действительно бесплатно?
A: ДА! Полностью бесплатно. Нет даже пробного периода - 
   это просто бесплатный сервис от Render.
