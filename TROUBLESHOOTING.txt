🔍 ДИАГНОСТИКА ПРОБЛЕМЫ

Если бот не работает, проверьте:

1. **Проверьте, скопирован ли токен правильно**
   - Откройте .env файл
   - Убедитесь, что BOT_TOKEN начинается с цифр (например: 123456789:ABC...)
   - Нет ли пробелов до или после токена

2. **Проверьте интернет соединение**
   - Ping 8.8.8.8
   - Telegram должен быть доступен

3. **Проверьте установку зависимостей**
   - Выполните: pip install -r requirements.txt
   - Убедитесь, что aiogram установлен: pip show aiogram

4. **Проверьте синтаксис Python файлов**
   - Выполните: python -m py_compile bot.py handlers.py content.py

🚀 ПОШАГОВЫЙ ЗАПУСК

ШАГИ:

1. Откройте CMD/PowerShell в папке проекта

2. Создайте виртуальное окружение (первый раз):
   python -m venv venv

3. Активируйте виртуальное окружение:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

4. Установите зависимости:
   pip install -r requirements.txt

5. Отредактируйте .env (скопируйте токен):
   notepad .env
   (или откройте в любом редакторе)

6. Запустите бота:
   python bot.py

7. Должны появиться логи вроде:
   INFO:root:✅ Примеры вакансий добавлены в базу данных
   INFO:root:🤖 Бот КОНТАНТА запущен...

❌ ОШИБКИ И РЕШЕНИЯ

Ошибка: "ModuleNotFoundError: No module named 'aiogram'"
Решение: 
  pip install aiogram==3.3.0

Ошибка: "BOT_TOKEN not set"
Решение:
  1. Проверьте наличие файла .env в папке проекта
  2. Убедитесь, что BOT_TOKEN там есть
  3. Перезагрузите бота

Ошибка: "ConnectionError" или "Timeout"
Решение:
  1. Проверьте интернет соединение
  2. Убедитесь, что Telegram не заблокирован
  3. Попробуйте перезагрузить компьютер

Ошибка: "Invalid bot token"
Решение:
  1. Скопируйте токен заново от @BotFather
  2. Убедитесь, что токен скопирован ПОЛНОСТЬЮ
  3. Нет ли пробелов?

📝 КОПИРОВАНИЕ ТОКЕНА

Когда BotFather отправит токен:

❌ НЕПРАВИЛЬНО:
   Просто нажать и скопировать ссылку сообщения

✅ ПРАВИЛЬНО:
   1. Выделить весь текст токена полностью
   2. Скопировать (Ctrl+C)
   3. Вставить в .env (Ctrl+V)
   4. Убедиться, что всё скопировалось целиком

Пример токена (ВАШ будет другим):
123456789:ABCDefGHIjklmNoPqrsTuvWxyz1234567890
↑                    ↑                        ↑
начало               двоеточие               конец

🆘 ЕСЛИ НИЧЕГО НЕ ПОМОГАЕТ

1. Проверьте все файлы на месте
2. Удалите виртуальное окружение: rm -r venv (Linux) или rmdir /s venv (Windows)
3. Пересоздайте всё сначала:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
4. Убедитесь, что Python версии 3.11+: python --version
5. Напишите ошибку полностью и её контекст
