🚀 БЫСТРЫЙ СТАРТ ЗА 5 МИНУТ

ШАГ 1: ПОЛУЧИТЬ BOT_TOKEN
─────────────────────────
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду: /newbot
3. Следуйте инструкциям
4. Скопируйте полученный токен

ШАГ 2: ПОДГОТОВИТЬ ФАЙЛЫ
─────────────────────────
1. Откройте файл .env.example
2. Замените "your_telegram_bot_token_here" на ваш токен
3. Сохраните как .env

ШАГ 3: ЗАПУСТИТЬ БОТ
──────────────────────

Вариант А (Docker Compose - рекомендуется):
   docker-compose up -d

Вариант Б (Python):
   pip install -r requirements.txt
   python bot.py

Вариант В (Windows PowerShell):
   python -m venv venv
   .\venv\Scripts\Activate
   pip install -r requirements.txt
   python bot.py

🔧 УСТАНОВКА И ЗАПУСК

╔════════════════════════════════════════════════════════════════╗
║ СПОСОБ 1: DOCKER COMPOSE (Рекомендуется)                     ║
╚════════════════════════════════════════════════════════════════╝

1. Установите Docker и Docker Compose
   https://docs.docker.com/get-docker/

2. Отредактируйте .env файл

3. Запустите:
   docker-compose up -d

4. Проверьте статус:
   docker-compose ps

5. Посмотрите логи:
   docker-compose logs -f

6. Остановка:
   docker-compose down


╔════════════════════════════════════════════════════════════════╗
║ СПОСОБ 2: PYTHON (Linux/Mac/Windows)                         ║
╚════════════════════════════════════════════════════════════════╝

1. Установите Python 3.11+ (если его нет)
   https://www.python.org/downloads/

2. Установите зависимости:
   pip install -r requirements.txt

3. Отредактируйте .env файл

4. Запустите бота:
   python bot.py

5. В консоли должны появиться логи вроде:
   INFO:root:🤖 Бот КОНТАНТА запущен...


╔════════════════════════════════════════════════════════════════╗
║ СПОСОБ 3: SYSTEMD (Для Linux серверов)                       ║
╚════════════════════════════════════════════════════════════════╝

1. Создайте файл /etc/systemd/system/kontanta_bot.service

2. Содержимое:
   [Unit]
   Description=Kontanta Telegram Bot
   After=network.target

   [Service]
   Type=simple
   User=www-data
   WorkingDirectory=/home/user/kontanta_bot
   ExecStart=/usr/bin/python3 /home/user/kontanta_bot/bot.py
   Restart=always

   [Install]
   WantedBy=multi-user.target

3. Включите сервис:
   sudo systemctl enable kontanta_bot
   sudo systemctl start kontanta_bot

4. Проверьте статус:
   sudo systemctl status kontanta_bot

❓ ЧАСТО ВСТРЕЧАЮЩИЕСЯ ПРОБЛЕМЫ

Проблема: "BOT_TOKEN не установлен"
Решение: 
  1. Проверьте наличие файла .env
  2. Убедитесь, что BOT_TOKEN скопирован правильно
  3. Перезагрузите бота

Проблема: "ModuleNotFoundError: No module named 'aiogram'"
Решение:
  pip install -r requirements.txt

Проблема: "Бот не отвечает на команды"
Решение:
  1. Проверьте логи: docker-compose logs -f
  2. Убедитесь, что боту правильно передан токен
  3. Отправьте /start в боте
  4. Перезагрузите: docker-compose restart

Проблема: "Port already in use (только для Docker)"
Решение:
  docker-compose down
  docker-compose up -d
