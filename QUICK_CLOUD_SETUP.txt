🎯 5 ШАГОВ К ЗАПУСКУ:

ШАГ 1: GitHub (1 минута)
────────────────────────

1. Перейдите на https://github.com/signup
2. Создайте аккаунт
3. После входа нажмите "+" → "New repository"
4. Назовите: kontanta-bot
5. Нажмите "Create repository"

ШАГ 2: Загрузить файлы на GitHub (2 минуты)
─────────────────────────────────────────

1. Откройте CMD в папке проекта:
   cd C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot

2. Выполните команды:

   git init
   git add .
   git commit -m "Deploy kontanta bot"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/kontanta-bot.git
   git push -u origin main

   (Замените YOUR_USERNAME на ваше имя GitHub)

ШАГ 3: Render регистрация (1 минута)
────────────────────────────────────

1. Перейдите на https://render.com
2. Нажмите "Sign up"
3. Выберите "Continue with GitHub"
4. Авторизуйтесь

ШАГ 4: Развернуть бота (1 минута)
─────────────────────────────────

1. На Render нажмите "+ New"
2. Выберите "Web Service"
3. Выберите "kontanta-bot" репозиторий
4. Нажмите "Connect"

Настройки:
├─ Name: kontanta-bot
├─ Environment: Python 3
├─ Build: pip install -r requirements.txt
└─ Start: python bot.py

5. Нажмите "Create Web Service"

ШАГ 5: Добавить переменные окружения (1 минута)
─────────────────────────────────────────────

1. На странице сервиса нажмите "Environment"
2. Добавьте переменные:

   BOT_TOKEN=123456789:ABCDefGHIjklmNoPqrsTuvWxyz...
   ADMIN_ID=5785752307
   WEBSITE_URL=https://www.kontanta.ru

3. Сохраните (автоматически перезагрузится)

═══════════════════════════════════════════════════════════════

✅ БОТ РАБОТАЕТ! 🎉

После загрузки увидите "Your service is live"

Откройте Telegram и напишите боту /start

БОТ БУДЕТ РАБОТАТЬ 24/7 БЕЗ ВЫКЛЮЧЕНИЯ!

═══════════════════════════════════════════════════════════════

🔄 ОБНОВЛЕНИЕ КОДА (если нужно изменить):

1. Измените файлы на ПК
2. В папке проекта:

   git add .
   git commit -m "Update"
   git push

3. Render автоматически обновится!
