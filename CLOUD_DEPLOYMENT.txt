✅ СПОСОБ #1: RENDER (РЕКОМЕНДУЕТСЯ)

ПРЕИМУЩЕСТВА:
✅ Полностью бесплатно
✅ Очень просто
✅ Бот работает 24/7
✅ Без карты (!)
✅ Поддержка Python

ШАГ 1: Создать GitHub аккаунт
─────────────────────────────

1. Перейдите на https://github.com/signup
2. Создайте аккаунт (email + пароль)
3. Подтвердите email

ШАГ 2: Загрузить проект на GitHub
──────────────────────────────────

1. На GitHub нажмите "+" → "New repository"
2. Назовите: "kontanta-bot"
3. Описание: "KONTANTA Telegram Bot"
4. Выберите "Public"
5. Нажмите "Create repository"

6. Откройте CMD/Terminal на вашем ПК
7. Перейдите в папку проекта:
   cd C:\Users\YourUser\Desktop\NKO\tmp\kontanta_bot

8. Инициализируйте git:
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/kontanta-bot.git
   git push -u origin main

ШАГ 3: Развернуть на Render
───────────────────────────

1. Перейдите на https://render.com
2. Нажмите "Sign up" → выберите GitHub
3. Авторизуйтесь через GitHub
4. На Render нажмите "+ New" → "Web Service"
5. Подключите репозиторий "kontanta-bot"

6. Настройки:
   - Name: kontanta-bot
   - Environment: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: python bot.py

7. Добавьте переменные окружения:
   Environment Variables:
   - BOT_TOKEN: [ваш токен]
   - ADMIN_ID: 5785752307
   - WEBSITE_URL: https://www.kontanta.ru

8. Нажмите "Create Web Service"

✅ БОТ РАБОТАЕТ! 🎉

✅ СПОСОБ #2: RAILWAY

ПРЕИМУЩЕСТВА:
✅ Очень простой интерфейс
✅ Бесплатно (первые $5/месяц)
✅ Легко развернуть

ШАГ 1: Создать аккаунт
──────────────────────
1. https://railway.app/
2. Нажмите "Login"
3. Выберите GitHub
4. Авторизуйтесь

ШАГ 2: Развернуть проект
─────────────────────────
1. Нажмите "New Project"
2. Выберите "Deploy from GitHub repo"
3. Подключите репозиторий kontanta-bot
4. Выберите Python

ШАГ 3: Добавить переменные
──────────────────────────
1. В "Variables" добавьте:
   BOT_TOKEN=ваш_токен
   ADMIN_ID=5785752307

2. Railway автоматически откроет порт

✅ БОТ РАБОТАЕТ! 🎉

✅ СПОСОБ #3: ORACLE CLOUD (МОЩНЫЙ, БЕСПЛАТНЫЙ)

ПРЕИМУЩЕСТВА:
✅ Полностью бесплатно (всегда!)
✅ Мощный сервер
✅ 24/7 без ограничений

ШАГ 1: Регистрация
──────────────────
1. https://www.oracle.com/cloud/free/
2. Нажмите "Start for free"
3. Создайте аккаунт (нужна карта для проверки)

ШАГ 2: Создать VM
─────────────────
1. В Oracle Cloud Console
2. "Compute" → "Instances"
3. "Create Instance"
4. Выберите Ubuntu 22.04
5. Выберите "Always Free" машину

ШАГ 3: Подключиться по SSH
───────────────────────────
1. Откройте Terminal/PowerShell
2. Скачайте SSH ключ с Oracle
3. Выполните:
   ssh ubuntu@ваш_ip_адрес

ШАГ 4: Установить бота
──────────────────────
1. На сервере выполните:

   # Обновить систему
   sudo apt update && sudo apt upgrade -y
   
   # Установить Python
   sudo apt install python3 python3-pip git -y
   
   # Клонировать проект
   git clone https://github.com/YOUR_USERNAME/kontanta-bot.git
   cd kontanta-bot
   
   # Установить зависимости
   pip3 install -r requirements.txt
   
   # Создать .env
   nano .env
   # Вставьте: BOT_TOKEN=ваш_токен
   # Ctrl+O, Enter, Ctrl+X

ШАГ 5: Запустить бота в фоне
─────────────────────────────
1. Выполните:
   
   screen -S bot
   python3 bot.py
   
   # Нажмите Ctrl+A, потом D
   
   # Бот работает в фоне!

2. Для подключения:
   screen -r bot
