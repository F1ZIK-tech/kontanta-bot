🔧 ПОСЛЕ ЗАПУСКА:

ЕСЛИ НУЖНО ИЗМЕНИТЬ КОД:

1. Измените файлы на ПК
2. git add . && git commit && git push
3. Render автоматически обновится

ЕСЛИ НУЖНО ПЕРЕЗАГРУЗИТЬ:

1. Render → Dashboard → ваш сервис
2. Нажмите "Suspend"
3. Нажмите "Resume"

ЕСЛИ НУЖНО СМОТРЕТЬ ЛОГИ:

1. Render → ваш сервис
2. Внизу справа → "Logs"
3. Видите всё что происходит
