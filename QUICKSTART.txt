ЭТАП 1: ПОЛУЧИТЬ ТОКЕН (2 минуты)
─────────────────────────────────────────

1. Откройте Telegram → найдите @BotFather
2. Отправьте: /newbot
3. На вопрос "Как должен называться ваш бот?" напишите:
   КОНТАНТА Recruiter
4. На вопрос "Выберите username для бота" напишите:
   kontanta_recruiter_bot
5. BotFather вернёт ТОКЕН (длинный текст с цифрами и буквами)
6. Скопируйте ВЕСЬ токен (от первой цифры до последней буквы)

Пример токена (ВАШ будет другой):
123456789:ABCDefGHIjklmNoPqrsTuvWxyz1234567890

═══════════════════════════════════════════════════════════════

ЭТАП 2: УСТАНОВИТЬ ТОКЕН (1 минута)
────────────────────────────────────

1. Откройте файл .env в текстовом редакторе (Notepad, VS Code и т.д.)
2. Найдите строку: BOT_TOKEN=your_telegram_bot_token_here
3. Замените на: BOT_TOKEN=123456789:ABCDefGHIjklmNoPqrsTuvWxyz1234567890
4. Сохраните файл

⚠️ ВАЖНО: 
   - Нет пробелов до или после токена
   - Нет кавычек вокруг токена
   - Скопирован ВЕСЬ токен (проверьте длину)

═══════════════════════════════════════════════════════════════

ЭТАП 3: ЗАПУСТИТЬ БОТ (2 минуты)
────────────────────────────────

WINDOWS:
1. Откройте CMD в папке проекта (или PowerShell)
2. Выполните: run_bot.bat
   
ИЛИ ручной запуск:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python bot.py

LINUX/MAC:
1. Откройте Terminal в папке проекта
2. Выполните: bash run_bot.sh
   
ИЛИ ручной запуск:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python3 bot.py

═══════════════════════════════════════════════════════════════

ЭТАП 4: ТЕСТИРОВАНИЕ
─────────────────────

1. Бот должен запуститься и в консоли появится:
   ✅ Примеры вакансий добавлены в базу данных
   🤖 Бот КОНТАНТА запущен...

2. Откройте Telegram
3. Найдите вашего бота (по username: @kontanta_recruiter_bot)
4. Отправьте /start
5. Бот должен ответить приветствием с вашим именем! ✅
