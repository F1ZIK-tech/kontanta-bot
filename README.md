# 🎖️ КОНТАНТА Telegram Bot

Официальный Telegram-бот для подбора профессионалов в элитные подразделения РФ.

## ✨ Функциональность

Бот предоставляет полную информацию о программе КОНТАНТА и позволяет подать заявку на вакансию:

- 🎖️ **О нас** - Информация об организации КОНТАНТА
- 📋 **Вакансии** - Просмотр вакансий по категориям (БПЛА, КАМАЗ, ИТ)
- 🎓 **Обучение** - Программы подготовки и переквалификации
- 💰 **Льготы и выплаты** - Полная информация о выплатах и преимуществах
- ❓ **Вопросы и ответы** - FAQ с ответами на популярные вопросы:
  - Как подать заявку?
  - Какие требования к кандидатам?
  - Процедура контрактации
  - Размер зарплаты
  - Сроки контракта
  - Возможности для семейных людей
- 💬 **Связаться с оператором** - Контактная информация
- 📞 **Контакты** - Полные контакты организации

- 📝 **Подача заявок** - Интерактивная форма для отправки заявки на вакансию
- 🗄️ **SQLite БД** - Хранение заявок, пользователей и вакансий

## 🚀 Быстрый старт

### Требования

- Python 3.11+
- Docker (опционально)
- Telegram Bot Token (от [@BotFather](https://t.me/botfather))

### Локальный запуск

1. **Клонируйте репозиторий:**
```bash
git clone <repo_url>
cd kontanta_bot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте `.env` файл:**
```bash
cp .env.example .env
```

4. **Откройте `.env` и добавьте ваш BOT_TOKEN:**
```
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=your_admin_telegram_id
WEBSITE_URL=https://www.kontanta.ru
```

5. **Запустите бота:**
```bash
python bot.py
```

### Docker запуск

1. **Постройте образ:**
```bash
docker build -t kontanta_bot .
```

2. **Запустите контейнер:**
```bash
docker run -d \
  --name kontanta_bot \
  -e BOT_TOKEN=your_token_here \
  -e ADMIN_ID=your_id_here \
  -v $(pwd)/data:/app/data \
  kontanta_bot
```

3. **Проверьте логи:**
```bash
docker logs -f kontanta_bot
```

### Docker Compose запуск (рекомендуется)

1. **Создайте `.env` файл:**
```bash
cp .env.example .env
```

2. **Отредактируйте `.env` и добавьте токен:**
```
BOT_TOKEN=your_token_here
ADMIN_ID=your_admin_id
WEBSITE_URL=https://www.kontanta.ru
```

3. **Запустите бота:**
```bash
docker-compose up -d
```

4. **Проверьте статус:**
```bash
docker-compose ps
```

5. **Остановите бота:**
```bash
docker-compose down
```

## 🔧 Конфигурация

### Переменные окружения

Отредактируйте `.env` файл:

```env
# Токен бота от @BotFather
BOT_TOKEN=your_bot_token_from_botfather

# Ваш Telegram ID (для админ функций)
ADMIN_ID=your_telegram_id

# Основной сайт
WEBSITE_URL=https://www.kontanta.ru
```

### Получить BOT_TOKEN

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env` файл

### Получить ADMIN_ID

1. Откройте Telegram и найдите [@userinfobot](https://t.me/userinfobot)
2. Отправьте `/start`
3. Скопируйте ваш ID в `.env` файл

## 🗄️ База данных

Бот использует SQLite для хранения:

- **vacancies** - Вакансии с описанием, требованиями, зарплатой
- **users** - Пользователи бота
- **applications** - Заявки кандидатов
- **subscriptions** - Подписки на категории вакансий
- **drafts** - Черновики незаконченных заявок

Файл БД: `kontanta.db` (создаётся автоматически)

## 🐛 Решение проблем

### Бот не запускается

**Проблема:** `ValueError: BOT_TOKEN не установлен`

**Решение:**
- Проверьте наличие файла `.env`
- Убедитесь, что там установлен BOT_TOKEN
- Проверьте, что токен корректный (без пробелов)

```bash
cat .env  # Linux/Mac
type .env # Windows
```

### Ошибка при подаче заявки

**Проблема:** `No such file or directory: 'kontanta.db'`

**Решение:**
- Проверьте права на запись в директорию проекта
- Создайте вручную: `touch kontanta.db`
- Перезапустите бота

### Бот не отвечает на сообщения

**Проблема:** Бот не реагирует на нажатие кнопок

**Решение:**
1. Проверьте логи: `docker logs kontanta_bot`
2. Убедитесь, что бот активен: `docker ps`
3. Перезагрузите бота: `docker restart kontanta_bot`
4. Или отправьте команду `/start` в боте
