🎖️ СТРУКТУРА ПРОЕКТА KONTANTA TELEGRAM BOT

═══════════════════════════════════════════════════════════════

📁 ГЛАВНЫЕ ФАЙЛЫ (Telegram Бот)
─────────────────────────────────────────────

🤖 bot.py
   Главный файл приложения
   Запуск: python bot.py
   Функции:
   - Инициализация бота
   - Загрузка переменных окружения
   - Запуск polling (прослушивание сообщений)
   - Инициализация БД с примерами вакансий

📝 handlers.py (12 КБ)
   Обработчики команд и callback'ов
   Содержит:
   - @start_handler - приветствие с именем пользователя
   - section_* - обработчики разделов (о нас, вакансии и т.д.)
   - category_handler - выбор категории вакансий
   - apply_handler - подача заявки
   - confirm_application - подтверждение заявки
   - FAQ обработчики
   - Навигация между разделами

🎹 keyboards.py (4 КБ)
   Клавиатуры и кнопки
   Содержит:
   - main_menu_keyboard() - главное меню (7 кнопок)
   - categories_keyboard() - выбор категории вакансий
   - vacancy_details_keyboard() - кнопки вакансии
   - faq_keyboard() - 6 FAQ вопросов
   - contact_keyboard() - контакты
   - confirmation_keyboard() - да/нет

💾 database.py (7 КБ)
   Работа с SQLite базой данных
   Таблицы:
   - vacancies - вакансии
   - users - пользователи
   - applications - заявки
   - subscriptions - подписки
   - drafts - черновики
   Методы:
   - add_user() - добавить пользователя
   - add_vacancy() - добавить вакансию
   - add_application() - добавить заявку
   - get_vacancies() - получить вакансии
   - И другие...

📄 content.py (32 КБ) 
   Все тексты и содержимое разделов
   Содержит:
   - WELCOME_MESSAGE_TEMPLATE - приветствие с {user_name}
   - ABOUT_SECTION - информация о КОНТАНТА
   - VACANCIES_INTRO - введение в раздел вакансий
   - TRAINING_SECTION - программы обучения
   - BENEFITS_SECTION - льготы и выплаты
   - FAQ_SECTION - заголовок FAQ
   - FAQ_DATA - 6 вопросов и ответов
   - HELP_SECTION - помощь
   - CONTACTS_SECTION - контакты

.env ⭐ ГЛАВНЫЙ ФАЙЛ
   Переменные окружения (ЗАПОЛНИТЬ ВАШИМ ТОКЕНОМ!)
   Содержит:
   BOT_TOKEN=123456789:ABCDefGHIjklmNoPqrsTuvWxyz1234567890
   ADMIN_ID=5785752307
   WEBSITE_URL=https://www.kontanta.ru

.env.example
   Пример .env файла
   Скопировать и переименовать в .env

requirements.txt
   Python зависимости:
   - aiogram==3.3.0 (Telegram Bot API)
   - python-dotenv==1.0.0 (переменные окружения)
   - sqlalchemy==2.0.23 (ORM)
   - aiohttp==3.9.1 (HTTP клиент)
   - beautifulsoup4==4.12.2 (парсинг HTML)
