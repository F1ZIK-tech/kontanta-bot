🚀 КАК ЗАПУСТИТЬ

WINDOWS:
  1. Откройте CMD/PowerShell в папке проекта
  2. Выполните: run_bot.bat
  
LINUX/MAC:
  1. Откройте Terminal
  2. Выполните: bash run_bot.sh

ИЛИ РУЧНОЙ ЗАПУСК (все ОС):
  python -m venv venv
  (Windows) venv\Scripts\activate
  (Linux/Mac) source venv/bin/activate
  pip install -r requirements.txt
  python bot.py
