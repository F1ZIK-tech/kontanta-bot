⚡ ПОШАГОВО (2 минуты)

1. Откройте PowerShell/CMD

2. Обновите pip:
   
   python -m pip install --upgrade pip

3. Очистите кэш pip:
   
   pip cache purge

4. Переустановите зависимости:
   
   pip install -r requirements.txt

5. Если всё ещё ошибка - используйте это:
   
   pip install aiogram==3.3.0 python-dotenv==1.0.0 aiohttp==3.9.1

6. Запустите бота:
   
   python bot.py
