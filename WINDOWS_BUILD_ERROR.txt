⚠️ РЕШЕНИЕ: pydantic-core wheel error на Windows

═══════════════════════════════════════════════════════════════

ПРОБЛЕМА:
Windows пытается компилировать pydantic-core, но нет компилятора C

═══════════════════════════════════════════════════════════════

✅ РЕШЕНИЕ #1 (РЕКОМЕНДУЕТСЯ - 3 шага)

1. Обновите pip:
   python -m pip install --upgrade pip

2. Установите пакет для сборки:
   pip install --upgrade setuptools wheel

3. Установите зависимости:
   pip install -r requirements.txt

═══════════════════════════════════════════════════════════════

✅ РЕШЕНИЕ #2 (если #1 не сработало)

Используйте pre-built wheels:

pip install --only-binary :all: aiogram python-dotenv

═══════════════════════════════════════════════════════════════

✅ РЕШЕНИЕ #3 (если ничего не помогает)

Установите необходимые tools на Windows:

1. Скачайте Microsoft C++ Build Tools:
   https://visualstudio.microsoft.com/visual-cpp-build-tools/

2. Установите и перезагрузитесь

3. Попробуйте pip install -r requirements.txt снова
