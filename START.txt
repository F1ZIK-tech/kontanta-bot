📋 БЫСТРАЯ ИНСТРУКЦИЯ (БЕЗ ЛИШНИХ СЛОВ)

ШАГИ:

1. Откройте .env файл и проверьте BOT_TOKEN

2. Откройте CMD/PowerShell в папке проекта

3. Windows - выполните:
   run_bot.bat

   Linux/Mac - выполните:
   bash run_bot.sh

   ИЛИ вручную для ВСЕХ ОС:
   python -m venv venv
   (Windows) venv\Scripts\activate
   (Linux/Mac) source venv/bin/activate
   pip install -r requirements.txt
   python bot.py

4. Когда увидите в консоли:
   🤖 Бот КОНТАНТА запущен...
   
   Бот работает! ✅

5. Откройте Telegram, найдите @kontanta_recruiter_bot
   и отправьте /start

⚠️ САМЫЕ ЧАСТЫЕ ОШИБКИ И РЕШЕНИЯ

────────────────────────────────────────────────────────────

❌ "BOT_TOKEN не установлен в .env файле"

✅ РЕШЕНИЕ:
   1. Откройте .env файл
   2. Проверьте строку BOT_TOKEN=...
   3. Убедитесь, что там ваш токен (начинается с цифр)
   4. Сохраните файл
   5. Перезапустите бота

────────────────────────────────────────────────────────────

❌ "ModuleNotFoundError: No module named 'aiogram'"

✅ РЕШЕНИЕ:
   pip install -r requirements.txt

────────────────────────────────────────────────────────────

❌ "ConnectionError" или "Timeout"

✅ РЕШЕНИЕ:
   1. Проверьте интернет
   2. Убедитесь, что Telegram не заблокирован
   3. Перезагрузите компьютер
   4. Попробуйте снова

────────────────────────────────────────────────────────────

❌ "python: command not found"

✅ РЕШЕНИЕ (для Linux/Mac):
   python3 -m venv venv
   source venv/bin/activate
   pip3 install -r requirements.txt
   python3 bot.py

────────────────────────────────────────────────────────────

❌ Бот не отвечает в Telegram

✅ РЕШЕНИЕ:
   1. Проверьте, запущен ли скрипт (консоль открыта)
   2. Отправьте /start в боте
   3. Проверьте правильность BOT_TOKEN
   4. Перезапустите бота

📊 ПОЛНЫЙ ПРОЦЕСС ЗАПУСКА

WINDOWS:
──────

1. Откройте папку проекта
2. Нажмите правой кнопкой → "Открыть PowerShell" (или CMD)
3. Выполните команду:
   run_bot.bat

4. Ждите логов вроде:
   ✅ Примеры вакансий добавлены в базу данных
   🤖 Бот КОНТАНТА запущен...

5. Открыт Telegram и тестируйте


LINUX/MAC:
──────────

1. Откройте Terminal
2. Перейдите в папку проекта:
   cd /path/to/kontanta_bot

3. Выполните команду:
   bash run_bot.sh

4. Ждите логов
5. Тестируйте в Telegram


DOCKER (если установлен):
─────────────────────────

1. Отредактируйте .env
2. Выполните:
   docker-compose up -d

3. Проверьте логи:
   docker-compose logs -f

4. Тестируйте в Telegram
